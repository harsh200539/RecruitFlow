# Five-minute interview walkthrough

1. Sign in as admin and explain the four scoped dashboard counts.
2. Show a job's recruiter and manager assignments.
3. Sign in as recruiter, create a candidate and upload a PDF.
4. Move sourcing to SCREENING, submit to an open job, then schedule an interview.
5. Sign in as hiring manager, review the assigned job and select/reject the submission.
6. Show tests proving another recruiter cannot fetch this candidate by changing the URL.

Discuss: join tables, object-level authorization, status transitions and pagination.
